# Server Health Monitor

A Python monitoring script that checks:

- CPU usage
- RAM usage
- Disk usage

## Technologies Used

- Python
- psutil

## Features

- Real-time CPU monitoring
- RAM usage tracking
- Disk utilization checks

## How to Run

```bash
pip install -r requirements.txt
python3 monitor.py
```

## Sample Output

```text
CPU Usage: 12.5%
RAM Usage: 48.3%
Disk Usage: 22.1%
```
